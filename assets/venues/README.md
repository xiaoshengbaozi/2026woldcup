# Venue Assets

High-resolution venue image library for FIFA World Cup 2026 match pages. Each venue folder contains `day.jpg` and `night.jpg`. Use `index.json` to map venue names to assets and choose the image by local match time.

Sources are Wikimedia Commons file pages. Review each `sourceUrl` for exact license and attribution before public release. Some night images are dusk, event-night, or lit-interior fallbacks where a clean open-license night exterior was not available.
