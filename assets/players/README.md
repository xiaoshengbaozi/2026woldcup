# Player Asset Library

This folder stores player visual assets grouped by national team.

## Folder Naming

Team folders use:

```text
FIFA_CODE-english-slug
```

Example:

```text
ESP-spain/headshots/
BRA-brazil/cards/
```

## Categories

- `headshots/`: cropped player portraits for lineup cards and detail panels.
- `full-body/`: full-body player cutouts or action poses.
- `cards/`: composed player card artwork or generated card variants.
- `raw/`: source downloads, references, or unprocessed originals.

## Suggested File Naming

Use lowercase ASCII names:

```text
player-name.png
player-name.webp
player-name-source.jpg
```

For numbered variants:

```text
player-name-01.webp
player-name-02.webp
```
