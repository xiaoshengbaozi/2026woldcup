# UI DESIGN RULES

This project must follow:

- futuristic dashboard UI
- premium glassmorphism
- dark luxury interface
- Apple Vision Pro aesthetics
- minimal layout
- floating cards
- soft glow
- neon accent
- high-end SaaS feel

Avoid:
- generic sports website
- cheap gradients
- esports style
- overcrowded layout
- heavy borders
- bootstrap appearance

Tech stack:
- Next.js
- TailwindCSS
- Framer Motion

UI requirements:
- rounded-3xl+
- backdrop blur
- smooth transitions
- responsive
- reusable components
- clean typography
