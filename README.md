# 2026 World Cup Calendar

This repository hosts a subscribable iCalendar feed for the 2026 FIFA World Cup schedule in Beijing time (Asia/Shanghai).

## Subscribe

After GitHub Pages is enabled for this repository, use:

```text
https://<your-github-username>.github.io/<repository-name>/calendar.ics
```

If this repository is named `<your-github-username>.github.io`, use:

```text
https://<your-github-username>.github.io/calendar.ics
```

## Files

- `calendar.ics`: stable subscription URL for calendar apps
- `2026世界杯赛程.ics`: original Chinese filename
- `index.html`: simple landing page with subscription links

## GitHub Pages Setup

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`, then save.

GitHub Pages may take a minute or two to publish the calendar URL.
